# 수용소 탈출기 - 종합 로어 문서 (Master Lore Document)

이 문서는 "수용소 탈출기" 텍스트 어드벤처 게임의 모든 로어와 설정을 총망라합니다.

---

## 게임 개요

**장르**: 텍스트 어드벤처, 탈출 게임, 심리 스릴러, 호러
**분위기**: 어둡고 냉소적, 메타적 서술
**플랫폼**: 웹 (Node.js/Express + React)
**언어**: 한국어
**주제**: 생존, 선택의 무게, 자유의 대가, 도덕적 딜레마

---

## 세계관

### 배경 설정
**시기**: 현대 (정확한 연도 불명)
**장소**: 정부 운영 수용소 (정식 명칭 불명)
**위치**: 외곽 지역, 10km 반경 출입 금지 구역
**주변**: 숲, 강 (하수도 연결)

### 수용소 역사
- 일제강점기 수도원 터 위에 건설됨
- 1943년 당시 수도원은 독립운동가 은신처로 사용
- 지하에 비밀 터널 존재 (수십 년간 방치)
- 3년 전 폭동 발생 (작업장에서 진압, 다수 사망)
- 지하 콘크리트에 시신 매장 의혹
- 시체 보관소로 냉동실 사용 (귀신 소문)

### 수용소 구조
**지상**:
- 복도 (녹슨 철문, 축축한 콘크리트)
- 감방 7번 (8명 수용)
- 작업장 (프레스 기계, 공구, 기름통)
- 식당 (회색 콘크리트, 배급구, 주방)
- 운동장 (담벼락 5m, 감시탑 2개, 벌집)
- 옥상 (전선, 배수관)
- 소장실 (마스터 터미널)

**지하**:
- 지하 1층: 창고
- 지하 2층: 보일러실, 환기 덕트
- 지하 3층: 하수도 맨홀 (외부 연결)
- 독방 (완전한 어둠, 벽 긁는 소리)

**던전 (일제 시대 터널)**:
- 무너진 벽 입구
- 낡은 벽돌 통로 (1943년)
- 창고 (철문, 아이템 보관)
- 침수 구역 (검은 물, 무언가 움직임)
- 지하 감옥 (해골들)
- 예배당 (폐허, 수호자)
- 비밀 통로 (출구)

## 스토리 타임라인

### 과거
- **1943년**: 일제강점기, 수도원 시대
  - 독립운동가 은신처
  - 지하 터널 사용
  - "수호자" 관련 사건 (수도사 일기 기록)
  - 12명이 예배당에서 미쳐버림

- **5년 전**: 주인공의 과거
  - 정부 보안 프로젝트 외주 수행
  - 보안 시스템 개발 (현재 수용소에 사용 중)
  - 디버그 백도어 남김 (출시 전 삭제 안 함)
  - 개발자 별명: PHANTOM_DEV

- **3년 전**: 수용소 폭동
  - 죄수들 봉기
  - 작업장에서 대규모 진압
  - 다수 사망
  - 이후 작업장에서 괴 현상 (긁는 소리, 기계 멈춤, 쥐 시체)

- **작년**: 탈출 시도
  - 한 죄수가 담벼락 철조망 등반
  - 벌집 건드림
  - 쏘여서 추락, 목 부러져 사망
  - 간수들이 벌집을 "자연 경비 시스템"으로 방치

- **한 달 전**: 작업장 사고
  - 프레스 기계에 손 끼임
  - "사고"로 처리
  - 치한 연루 의혹 (목격자: 아내 살인범)

- **며칠 전**: 쪽지의 주인
  - 7번 감방 이전 수용자
  - 독방 다녀온 후 정신 붕괴
  - 의무실 수용 중
  - 남긴 쪽지: "밤에 화장실 가지 마라"

### 현재 (게임 시작)
**1일차 - 입소**:
- 주인공 수감 (10년형)
- 간수와 첫 대면 (4가지 선택지)
- 7번 감방 배정
- 8명 죄수들과 만남
- 첫날 밤: 환기구 소리, 악몽

**2일차 - 적응**:
- 작업장 노동
- 운동장 활동
- 식당 이벤트
- 교육 프로그램 (선택)
- 동맹 형성 시작
- 정보 수집
- 밤: 방화범의 제안, 소아성폭력범 린치

**3일차 - 준비**:
- 작업장에서 에러 코드 발견 (TRUE ADMIN 단서)
- 아이템 획득 (드라이버, 기름, 열쇠 등)
- 최종 동맹 결정
- 탈출 루트 확정
- 수요일 밤 임박

**4일차 새벽 - 실행**:
- 새벽 2시: 간수장 의무실 (골든타임)
- 탈출 실행
- 다양한 루트와 엔딩 분기

## 주요 인물 (8명의 죄수)

### 1. 메시아 (Messiah)
- **범죄**: 사이비 종교 ("천상의 문")
- **배경**: 의사 → 기적 → 교주
- **성격**: 카리스마, 광기, 예언자 행세
- **계획**: 외부 신도 연계, 정전 + 환기구 탈출
- **관계**: 방화범과 적대, 주인공을 "창조자"로 특별 대우
- **엔딩**: A+, A

### 2. 사기꾼 (Fraudster, 김 사장)
- **범죄**: 127억 사기
- **배경**: 회사원 → 배신당함 → 사기꾼
- **성격**: 능글, 계산적, 정보상
- **약점**: 할머니 투신 사건 죄책감
- **계획**: 박 간수 매수 (5천만 원)
- **엔딩**: B, M

### 3. 아내 살인범 (Wifekiller)
- **범죄**: 아내 살해 (정당방위)
- **배경**: 가정폭력 피해자, 아들 보호
- **성격**: 과묵, 성실, 신뢰 가능
- **제공**: 지하 구조도, 비상구 정보
- **엔딩**: L

### 4. 치한 (Groper)
- **범죄**: 지하철 성추행 50회 이상
- **배경**: 23명 피해자, 귀 잘림
- **성격**: 음침, 복수심, 교활
- **위험**: 프레스 사고 유발
- **정보**: 간수장 불륜

### 5. 방화범 (Arsonist)
- **범죄**: 방화 (고아원 12명 사망)
- **배경**: 가정폭력 → 아버지 살해 → 연쇄 방화
- **성격**: 불안정, 광기, 내면 죄책감
- **계획**: 수용소 방화 → 혼란 탈출
- **엔딩**: C+, C

### 6. 소아성폭력범 (Pedophile)
- **범죄**: 소아 성폭력
- **성격**: 비굴, 공격적 내면, 반성 없음
- **상태**: 지속적 린치 피해
- **정보**: 환기 덕트, 간수장 스캔들

### 7. 정치범 (Political)
- **범죄**: 정부 비리 폭로
- **배경**: 기자 → 반역죄, 남편 사망
- **성격**: 냉철, 이성적, 신중
- **제공**: 지하 터널 정보, 교란 작전
- **엔딩**: N, O

### 8. 간수장 정 대위
- **약점**: 아들 병원비, 간호사 불륜
- **패턴**: 수요일 밤 면회, 새벽 2~3시 의무실
- **정보**: 환기구 카드키 소지
- **협상**: 협박 가능

**수감**: 정부 수용소

5. 디지털 복수 (엔딩 S)

### 던전 시스템 (초자연 루트)
**역사**: 1943년 수도원 터널

**수호자**:
- 눈 없는 수도사 형상
- 검은 그림자
- 정신 공격
- "죄책감의 응집체"

**대처법 3가지**:
1. 십자가 목걸이 (빛 발함)
2. 성경 + 주님의 기도 (메시아 가르침)
3. 죄 인정 + 속죄 의지 (수도사 일기)

**보상**: 비밀 통로 → 숲 → 자유

## 주요 테마

### 1. 선택의 무게
- 모든 선택이 결과를 가짐
- 동맹은 빚을 의미
- 혼자는 어렵지만 자유로움
- 타인을 이용하면 대가 존재

### 2. 도덕적 회색지대
- 주인공의 죄 (게임 vs 실제 범죄)
- 다른 죄수들의 복잡한 사연
- 정의 vs 복수 (디지털 복수 엔딩)
- 생존 vs 양심 (방화 루트)

### 3. 메타 서사
- 게임 개발자가 게임을 플레이하듯 현실을 봄
- "레벨 디자인", "NPC", "분기", "엔딩"
- "세이브 포인트 없음"의 공포
- 현실과 게임의 경계 모호

### 4. 자유의 대가
- 탈출 = 자유인가?
- 메시아 루트: 또 다른 족쇄
- 사기꾼 루트: 빚과 조직
- 방화 루트: 죄책감
- TRUE ADMIN: 권력의 유혹

### 5. 공포와 광기
- 독방의 고독
- 수호자의 초자연
- 냉동실 귀신
- 하수구 소리
- 정신 붕괴의 공포

- 심리적 압박 (선택, 시간, 감시)

### 언어
- 한국어 (비속어 포함)
- 간수: 반말, 폭력적
- 죄수들: 각자 말투 (메시아: 설교조, 사기꾼: 능글, 정치범: 지적)
- 주인공: 냉소, 자조, 메타

## 게임 플로우

```
입소 → 1일차 (환경 파악)
    → 2일차 (정보 수집, 동맹 형성)
        → 3일차 (준비 완료, 루트 선택)
            → 4일차 새벽 (탈출 실행)
                → 엔딩 (성공 13종 / 실패 6종 / GAME OVER 5종 / 던전 2종)
```

**주요 분기점**:
- 입소 첫 대면 (간수 관계)
- 감방 첫 만남 (죄수 관계)
- 메시아/사기꾼/방화범/정치범 선택
- 소아성폭력범 린치 (도움 vs 무시)
- 교육 참여 (모범수 루트)
- TRUE ADMIN 발견 (백도어 루트)
- 던전 진입 (초자연 루트)
- 최종 선택 (탈출 방식)
