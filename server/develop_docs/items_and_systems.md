# 아이템 및 시스템 (Items and Game Systems)

## 주요 아이템

### 입수 가능 아이템

#### 간수 관련
**가죽 채찍** - 간수 소지품 (입소 장면)
**열쇠 꾸러미** - 간수장 소지
- 큰 녹슨 열쇠 1개
- 작고 반짝이는 열쇠 2개
- 특수 카드키 1개 (환기구용)

**환기구 카드키** - 메시아 루트 핵심 아이템
- 간수장 허리춤에 있음
- 환기구 잠금장치 개방
- 입수 방법:
  1. 작업장에서 도둑질 (주변 파악 후)
  2. 소아성폭력범의 도움 (주의 분산)

---

#### 음식 및 담배
**묽은 죽** - 식당 배식
**딱딱한 빵** - 식당 배식
**박하 사탕** - 간수가 입소 시 주는 것 (유통기한 15년 지남)
**빵 조각** - 친해진 간수가 야간에 제공
**담배 한 갑** - 모범수 보상, 거래용 화폐
**담배 한 보루** - 사기꾼과의 거래 대가

---

#### 도구 및 무기
**작은 드라이버** - 작업장에서 훔침
- 자물쇠 따기 가능
- 나사 풀기
- 소매 안에 숨김

**녹슨 철사** - 창고에서 발견
- 자물쇠 따기 보조

**라이터 기름** - 작업장에서 빼돌림
- 방화범 루트 필수
- 심장이 뛰는 긴장 상황

**코딩 입문서** - 직업 훈련실 자료실
- 낙서에 비밀번호 힌트
- "0은 무, 9는 전부, 5는 균형"
- "중간은 5. 균형점."

---

#### 정보 아이템
**수용소 배치도** - 창고에서 발견
- 비상구와 환기구 위치 표시
- 모범수가 창고 임무 시 획득 가능

**지하 구조도** - 아내 살인범이 그려줌
- 10년 경험의 정보
- 비상구 위치

**교육 이수증** - 교육 프로그램 성실 참여 보상
- 가석방 심사에 유리
- 10년형 감형 가능성

**편지** - 정치범이 딸 민아에게 쓴 편지
- 5년 동안 부치지 못함
- 탈출 시 전달 약속

**증거 사진** - 간수 부패 증거
- 박 간수가 죄수에게 뇌물 받는 장면
- 협박용

---

#### 던전 아이템
**수도사 일기** (1943년)
- 터널 벽 옆에서 발견
- "지하 예배당의 수호자를 조심하라"
- 수호자 대처법: 죄 인정 + 속죄 의지

**방수 손전등**
- 던전 창고에서 발견
- 배터리 남아 있음 (최근에 누군가 사용)
- 던전 탐색 필수

**튼튼한 밧줄**
- 던전 창고
- 침수 구역 건너기용
- 삼베 재질, 상태 양호

**녹슨 곡괭이**
- 던전 창고
- 무너진 벽 파기용
- 사용 시 부러짐

**오래된 열쇠** (구리)
- 예배당 바닥에서 발견
- 던전 철문 개방

**성경책**
- 예배당 의자 위
- "주님의 기도" 구절에 밑줄
- 수호자 퇴치용 (기도 외우기)

**십자가 목걸이** (은)
- 석관 옆 상자
- 수호자 물리칠 때 빛을 발함
- 마음을 편안하게 하는 효과

**고문서** (한문, 일본어)
- 지하 감옥에서 발견
- 수호자 정보: "죄책감의 응집체"
- 대처법: 십자가 + 주님의 기도

## 게임 시스템

### 관계 시스템
**8명의 NPC와 관계 수치 존재**
- messiah (메시아)
- fraudster (사기꾼)
- wifekiller (아내 살인범)
- groper (치한)
- arsonist (방화범)
- pedophile (소아성폭력범)
- political (정치범)
- guard (간수)

**관계도 변화**:
- 선택지에 따라 호감도 증가/감소
- 특정 관계 수치가 높으면 특별 정보 제공
- 적대 관계 시 위험 (공격, 방해)
- 동맹 형성 시 탈출 루트 개방

---

### 플래그 시스템
**주요 플래그들**:
- `hasKey` - 특정 열쇠 보유
- `messiah_trust` - 메시아 신뢰 여부
- `arsonist_oil_given` - 방화범에게 기름 제공
- `fraudster_debt` - 사기꾼에게 빚
- `model_prisoner` - 모범수 지위
- `guard_friendly` - 간수와 우호적
- `guard_hostile` - 간수와 적대적
- `discovered_dungeon` - 던전 발견
- `defeated_guardian` - 수호자 물리침
- `true_admin_unlocked` - TRUE ADMIN 권한 획득

---

### 인벤토리 시스템
**소지품 제한**: 합리적 범위 내 (주머니 크기)
**숨김 가능**: 드라이버, 철사, 기름병 등 작은 물건
**발각 위험**: 소지품 검사 시 발각 가능

---

### 시간 시스템
**일차별 진행**:
- 1일차: 입소, 첫 만남, 환경 파악
- 2일차: 정보 수집, 관계 형성, 교육 참여
- 3일차: 준비 완료, 최종 선택
- 4일차 새벽: 탈출 실행

**시간대별 이벤트**:
- 아침: 기상, 점호
- 오전: 작업장
- 점심: 식당
- 오후: 작업장 또는 운동장
- 저녁: 교육 프로그램 (선택)
- 밤: 소등, 야간 활동 (자물쇠 따고 나가기)
- 새벽 2~3시: 골든타임 (간수장 부재)

**특수 요일**:
- 수요일 밤: 간수장 외출 (아들 면회)
- 가장 보안이 약한 시간
- 여러 탈출 루트의 실행 타이밍

---

### 교육 시스템
**교육 프로그램 2종**:

**정신 교육**:
- "반성과 미래"
- 참여 시: 평가 상승, 교육 이수증
- 졸 때: 효과 없음

**직업 훈련**:
- 전기 배선 교육
- 집중 시: 전기 지식 획득, 보안 시스템 이해
- 대충 시: 효과 없음
- 자료실 탐색: 코딩 입문서 발견, 비밀번호 힌트

**보상**:
- 교육 이수증 (가석방 유리)
- 평가 상승
- 특별 배식권

---

### 모범수 시스템
**획득 조건**:
- 작업 성실히 수행
- 교육 프로그램 참여
- 간수와 우호적 관계

**특혜**:
- 담배 제공
- 창고 정리 임무 (탐색 기회)
- 소장실 청소 임무 (TRUE ADMIN 루트)
- 추가 식사
- 감시 완화

**간수장 추천**:
- 모범수 명단 등록
- 특별 배식권
- 가석방 심사 유리

---

### TRUE ADMIN 시스템 (핵심 시스템)

**발견 과정**:
1. 작업장 구석 모니터에서 에러 코드 발견
2. "Error: 0x4E_GHOST - Protocol Timeout"
3. 주인공이 5년 전 개발한 시스템임을 깨달음
4. 마스터 터미널이 소장실에 있다고 추리

**접근 방법 3가지**:

**A. 모범수 루트**:
- 작업 성실, 교육 참여
- 간수 호감도 상승
- 소장실 청소 임무 배정 (15분 제한)

**B. 협박 루트**:
- 간수 부패 증거 수집
- 야간 근무 간수 협박
- 열쇠 10분 빌리기

**C. 침투 루트**:
- 야간 환기구 통해 침입
- 드라이버로 환기구 개방
- 소음 내면 발각

**로그인 과정**:
1. USERNAME 입력
   - 정답: `PHANTOM_DEV`
   - 소장실 서랍에서 명함 발견 가능
   - 또는 자신의 별명 기억

2. PASSWORD 입력
   - 힌트: "가장 어두운 곳에서 빛을 향해"
   - 직업 훈련실 코딩 입문서의 낙서 필요
   - 정답: `059`
   - 0 (어둠) → 5 (균형) → 9 (빛)
   - 3회 실패 시 경보

**권한 획득 후 가능한 행동**:

**시스템 제어**:
- CCTV 네트워크 (전체 감시 제어)
- 문 제어 (모든 문 개폐)
- 경보 시스템 (비활성화)
- PA 방송 (전체 또는 구역별)
- 순찰 일정 (간격 조작 가능)
- 수감자 데이터베이스
- 공급 명세서
- 비상 무효화
- 소장 개인 파일 (횡령, 학대, 은폐 증거)
- **감방 마스터 락** (모든 감방 동시 개방)

**선택지 5가지**:

1. **솔로 탈출** (엔딩 F)
   - CCTV 특정 구역 비활성화
   - 비상구 B 개방
   - 경보 우회
   - 순찰 15분 간격 생성
   - 조용히 탈출

2. **소장 협박** (엔딩 J)
   - 개인 파일 출력
   - 소장 독대
   - 비상구 개방 요구
   - 거래 성사

3. **대해방** (엔딩 Q)
   - 감방 마스터 락 해제
   - 317명 동시 석방
   - 대혼란 발생
   - 틈타서 탈출
   - 폭동, 불길, 살인 발생

4. **유령 프로토콜** (엔딩 R)
   - 수감자 기록 삭제
   - CCTV 아카이브 30일분 삭제
   - 접근 로그 삭제
   - 지문 데이터베이스 삭제
   - 석방 문서 위조
   - "존재하지 않는 사람"으로 정문 통과

5. **디지털 복수** (엔딩 S)
   - 대상 감방 카메라 비활성화 (치한)
   - 주변 감방 문 개방
   - PA 방송: "주의. 죄수 #1847은 소아성범죄자입니다. 감방 문이 열렸습니다."
   - 린치 유도
   - 하수도로 탈출

**메시지 남기기**:
```
>> 'Thank you for the opportunity. - PHANTOM_DEV'
```

### 던전 시스템

**진입 조건**:
- 지하실 발견
- 무너진 벽 발견
- 방수 손전등 필요 (어두우면 진입 불가)

**탐색 구조**:
```
입구 → 터널 → 세 갈래 길
         ├─ 동쪽 통로 (창고, 침수 구역)
         ├─ 예배당 (수호자)
         └─ 입구
```

**아이템 수집**:
- 수도사 일기
- 방수 손전등
- 밧줄
- 곡괭이
- 오래된 열쇠
- 성경책
- 십자가 목걸이
- 고문서

**수호자 전투**:
- 눈 없는 수도사 형상
- 정신 공격
- 3가지 대처법:
  1. 십자가 목걸이 들기 → 빛 발하며 퇴치
  2. 성경책 + 주님의 기도 → 고통스럽게 무릎 꿇음
  3. 죄 인정 + 속죄 의지 → 고개 끄덕이고 비밀 통로 개방

**탈출 성공**:
- 비밀 통로 → 달빛 → 숲 → 자유

**실패**:
- 도망치면 공포 지속, 정신 붕괴
- 아무것도 없이 맞서면 제물이 됨

## 중요 선택지와 결과

### 입소 첫 대면 (간수와의 관계 결정)
1. **고개 숙이고 빌기** → 간수 호감 (`guard_friendly`)
2. **노려보기** → 무릎 맞고 다리 부상, 간수 적대 (`guard_hostile`)
3. **사탕 태클** → 간수를 "별종"으로 인식
4. **열쇠 관찰** → 정보 획득 (열쇠 4개 구조)

### 감방 첫 만남
1. **자기소개** → 자연스러운 관계 형성
2. **구조 파악** → 탈출 정보 획득
3. **조용히 침대** → 쪽지 발견 이벤트

### 메시아 대응
1. **믿음 표현** → 메시아 루트 개방
2. **의심** → 중립
3. **사이비 모욕** → 적대, GAME OVER 위험

### 방화범 제안
1. **동의** → 방화 루트 개방
2. **거부** → 안전하나 루트 차단
3. **설득** → 피해 최소화 루트

### 소아성폭력범 린치
1. **도와줌** → 정보 획득, 다른 죄수들의 경멸
2. **무시** → 그가 중태, 정보 상실

### 교육 참여
1. **성실 참여** → 보상, 평가 상승
2. **졸기** → 효과 없음
3. **불참** → 기회 상실

### TRUE ADMIN 선택
1. **솔로 탈출** → 깔끔한 자유
2. **협박** → 어둠의 거래
3. **대해방** → 혼돈의 신
4. **유령** → 완벽한 소거
5. **복수** → 디지털 살인

각 선택은 엔딩과 직결되며, 일부는 돌이킬 수 없음.
